# Демосайты шинного сервиса Шымкента

Четыре демонстрационные концепции: MaX 24/7, TAY 24/7, Prodajadisko и GR Шин Маркет.

Это демонстрационные, а не официальные сайты компаний. Контакты и сведения получены из открытых источников; перед коммерческим запуском требуется согласование с владельцами. Данные GR не подтверждены. Настоящие фотографии и цитаты отзывов не подменены вымышленными материалами.

## Просмотр

- Главная витрина: `index.html`
- MaX: `max/`
- TAY: `tay/`
- Prodajadisko: `prodajadisko/`
- GR: `gr/`

Готовые статические HTML/CSS/JS, без установки зависимостей и серверной части. GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).

Карты и внешние контактные сервисы требуют доступа к интернету. Кнопки WhatsApp открывают чат с подготовленным вопросом; сообщения сайт не отправляет.

Иконки Simple Icons: лицензия и источники находятся в `assets/icons/`.
