# Simple Icons

Получено 9 ноября 2026 года из официального репозитория Simple Icons.

- https://raw.githubusercontent.com/simple-icons/simple-icons/develop/icons/whatsapp.svg
- https://raw.githubusercontent.com/simple-icons/simple-icons/develop/icons/telegram.svg
- https://raw.githubusercontent.com/simple-icons/simple-icons/develop/icons/instagram.svg
- Лицензия: https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md — CC0-1.0; полный текст сохранён рядом в LICENSE.md.

Файлы SVG сохранены без изменения. В HTML используются inline-копии, для которых добавлены `aria-hidden="true"`, `focusable="false"`, `fill="currentColor"` и класс `social-icon`, удалён избыточный title. Название каждой сети остаётся текстом ссылки.
